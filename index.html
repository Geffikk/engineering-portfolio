Real-time trading infrastructure

Cross-venue arbitrage platform

Detects a priced edge across two venues and places both legs automatically, with real money, under code-enforced risk limits.

  • Live prices over WebSocket from two independent venues, paired per fixture
  • Atomic execution authority in Redis: single writer, fencing, idempotent commands
  • Code-enforced risk limits and a named terminal state for every job

Equity valuation platform

Turns regulatory filings into auditable valuations and tracks a real portfolio against them. Language models never supply a number.

  • Valuations computed from regulatory filings, hashed so they can be replayed
  • Mongo job queues with leases, so a dead worker never loses a job
  • LLM research admitted only on verified citations, and it supplies no numbers
PythonFlask Next.jsMongoDB queues Playwright / CDP2,568 tests no order path

Football forecasting framework

Predicts football events from engineered features, then checks whether those predictions would actually have made money against real bookmaker odds.

  • Leak-free rolling backtest: the model never sees a result before predicting it
  • Engineered features from six sources: ELO, form, expected goals, squad power
  • A custom Keras loss that penalises agreeing with the bookmaker
